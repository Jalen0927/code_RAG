### Day 1(周一)— 哈希表入门

| 题号 | 题目 | 难度 | 考点 | Agent 场景关联 |
|---|---|---|---|---|
| 1 | 两数之和 | 简单 | 哈希表查补集 | 工具参数配对 |
| 217 | 存在重复元素 | 简单 | 哈希表判重 | chunk 去重(你的 RAG 项目用过) |

**今日重点**:理解"用空间换时间"的思想。哈希表查找 O(1),比暴力 O(n²) 快。

**手写模板**:
```python
def twoSum(nums, target):
    seen = {}  # 哈希表存 {值: 索引}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
```

### Day 8(周一)— 链表基础

| 题号 | 题目 | 难度 | 考点 | Agent 场景关联 |
|---|---|---|---|---|
| 206 | 反转链表 | 简单 | 链表指针操作 | **面试必考,必须手写熟练** |
| 21 | 合并两个有序链表 | 简单 | 链表合并 | 消息队列合并 |

**今日重点**:反转链表是**面试白板第一题**的概率极高。必须做到 3 分钟内写出来。

**手写模板**:
```python
def reverseList(head):
    prev, curr = None, head
    while curr:
        next_temp = curr.next  # 暂存下一个
        curr.next = prev       # 反转指向
        prev = curr            # prev 前进
        curr = next_temp       # curr 前进
    return prev
```

### Day 11(周四)— 二分查找基础

| 题号 | 题目 | 难度 | 考点 | Agent 场景关联 |
|---|---|---|---|---|
| 704 | 二分查找 | 简单 | 二分模板 | 向量库检索(你的项目底层) |
| 35 | 搜索插入位置 | 简单 | 二分变体 | — |

**今日重点**:二分查找模板必须背熟。`left <= right` 还是 `left < right`,边界要清晰。

**手写模板**:
```python
def search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**今日重点**:滑动窗口是 Agent 岗**高频考点**。你的 [_split_with_overlap](file:///d:/code_RAG/ingestion/code_splitter.py) 已经用了滑动窗口思想,面试时可以结合项目讲。

**手写模板**:
```python
def lengthOfLongestSubstring(s):
    char_set = set()
    left = 0
    max_len = 0
    for right in range(len(s)):
        while s[right] in char_set:  # 有重复,收缩左边界
            char_set.remove(s[left])
            left += 1
        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)
    return max_len
```

**今日重点**:Agent 开发天天处理 LLM 返回的 JSON,递归解析嵌套结构是核心技能。

**自定义题示例**:
```python
# 展平嵌套字典
# 输入: {"a": 1, "b": {"c": 2, "d": {"e": 3}}}
# 输出: {"a": 1, "b.c": 2, "b.d.e": 3}

def flatten_dict(d, prefix=""):
    result = {}
    for k, v in d.items():
        new_key = f"{prefix}.{k}" if prefix else k
        if isinstance(v, dict):
            result.update(flatten_dict(v, new_key))
        else:
            result[new_key] = v
    return result
```
